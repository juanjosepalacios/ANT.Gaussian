Half Mn contact Mn9-Mn4-Mn given as a z-matrix (multiplicity 71), UBPBE.

Each subdirectory is one variation of the calculation for this structure, with its own inputs,
outputs and README. The files keep the name of the system, `Mn9-Mn4-Mn`.

- [spd-ghost-opt/](spd-ghost-opt/README.md): Bethe lattice on one side, ghost on the other,
  geometry optimization. Does not finish.
