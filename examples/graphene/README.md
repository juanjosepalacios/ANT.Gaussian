Graphene examples.

- [nanographene/](nanographene/README.md): 170-atom nanographene flake with a carbon Bethe-lattice
  electrode around its edge; the local DOS of a central atom and the spin density.

The other files in this directory (`graphene-ribbon`, `nanographene`, `nanographene2`,
`hydrophene-ribbon`, `graphene.ant`) are the original inputs of these examples; only
`graphene-ribbon.log` has a stored output, from an older version of ANT.
