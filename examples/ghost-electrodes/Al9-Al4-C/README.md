A C atom adsorbed on an Al9-Al4 pyramid (15 atoms), UBLYP.

Each subdirectory is one variation of the calculation for this structure, with its own inputs,
outputs and README. The files keep the name of the system, `Al9-Al4-C`.

- [sp-ghost-opt/](sp-ghost-opt/README.md): Bethe lattice on the Al side, ghost on the other, with a
  geometry optimization.
