Case 4 of the [Pt nanocontact examples](../README.md): case 3 restarted with every atom listed in
`SPINROTATOM` at theta = 0, phi = 0, which rotates nothing but goes through the same spinor code as
case 5.

Copy `../mag/P.Pt9-Pt4-Pt-Pt-Pt4-Pt9.dat` here, then run `Pt9-Pt4-Pt-Pt-Pt4-Pt9.gjf` with
`Pt9-Pt4-Pt-Pt-Pt4-Pt9.ant`. The `.gjf` and basis are those of [case 3](../mag/README.md).
