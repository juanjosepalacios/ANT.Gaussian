Atomistic NanoTransport

Input files

An ANT.Gaussian09 calculation uses a Gaussian input file, an ANT control file and, for Bethe lattice electrodes, tight-binding parameter files.

Gaussian input file

The job_name.com file defines the geometry, electronic-structure method and basis set, together with the setup required to connect Gaussian and ANT.

Gaussian input setup and examples →

ANT control file

The job_name.ant file contains the ANT options and parameters for the calculation.

Bethe lattice parameter files

Files in BLDAT provide tight-binding parameters for Bethe lattice electrodes.
