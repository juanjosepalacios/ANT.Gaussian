ANT.Gaussian16

Installation instructions

Choose your interface: ANT.Gaussian09 installation · ANT.Gaussian16 installation

ANT.Gaussian16 uses the ANT-Gau-Open Python interface and the PyANT Fortran extension. These steps follow the repository’s current installation guide. Source access is restricted to authorised users.

Prerequisites

  • A working Gaussian16 installation and its configured shell environment. GauOpen also requires Tcsh and access to Gaussian utilities such as inp2mat.
  • A Fortran compiler such as GNU Fortran, plus BLAS/LAPACK libraries. On Debian-based systems, install gfortran, libblas-dev, liblapack-dev (or OpenBLAS), and tcsh.
  • Python 3.9 or 3.10, as required by the current package. The documented Nox workflow selects Python 3.9; the installation guide uses Pyenv Python 3.9.16 and Poetry 1.4.2.
  • Access to the GauOpen 3 dependency provided through the project’s configured SIMUNE package source.

The repository documents a legacy PyANT compatibility issue with stack-protected Python builds and recommends its dedicated Pyenv environment. Follow the project’s supported environment guidance and consult the maintainers if your system differs. The steps below describe that documented configuration; they have not been freshly compiled or tested for this website.

1. Get the source

Register your SSH key with a GitHub account authorised for the private repository, then clone it:

git clone git@github.com:juanjosepalacios/ANT.Gaussian16.git
cd ANT.Gaussian16

For Gaussian16 revision C.01, review the supplied patches/inp2mat.patch and the repository instructions before preparing the Gaussian utility.

2. Prepare Python

Install and initialise Pyenv following its official instructions, including Python build dependencies. The project guide specifies PYTHON_CONFIGURE_OPTS="--enable-shared" before building the interpreter. From the repository directory:

pyenv install 3.9.16
pyenv local 3.9.16
python -m pip install --upgrade nox poetry==1.4.2

3. Build PyANT

nox -s build

This builds the Fortran extension using Meson/Ninja and copies it into src/ant_gau_open/. To request OpenMP and explicitly select linear algebra libraries:

nox -s build -- -Dwith_openmp=enabled -Dwith_linalg='-llapack -lblas'

Check pyant/README.md for build options. Keep only the intended ant.*.so extension in the package directory.

4. Install and check the command

poetry install
poetry run ant-gau-open --help

Poetry installs the Python dependencies, including GauOpen, from the configured sources. If a dependency is unavailable or access is denied, contact the maintainers for the supported package and access instructions.

5. Run an example

Activate your valid Gaussian environment, then set ANT to the absolute path of this checkout:

export ANT="$(pwd)"
cd "$ANT/examples/Al-nanocontact/hf_linear"
poetry run ant-gau-open Al4-Al-Al-Al4.com

Check the calculation log and generated outputs. If inp2mat cannot be found or executed, check the Gaussian environment and that Tcsh is installed.

Full installation guide and environment limitations: INSTALL.md (authorised users). The repository remains private.

Command-line options

Run the installed command directly, or prefix it with poetry run in the Poetry environment:

poetry run ant-gau-open INPUT_FILE [OPTIONS]
poetry run ant-gau-open --help

INPUT_FILE is required: it is the Gaussian input file specifying the contact geometry and basis, or a restart input supported by the program. The following table lists every option defined by the current command-line parser.

OptionDefaultDescription
-h, --help—Show command-line help and exit.
-m, --num-scf-max N1000Maximum number of SCF cycles (integer).
-t, --convergence-tolerance VALUE1e-6Convergence threshold for the RMS density-matrix change (real).
-d, --debug LEVEL0Diagnostic print level (integer); higher levels print additional information.
-x, --model-xc MODELhfGaussian computational model / exchange-correlation keyword. The parser documents hf and lsda.
--mixing-type TYPEpulayDensity mixing for SCF with leads: linear or pulay.
--mixing-max-size N20Maximum Pulay history size (integer).
-g, --noant N00 runs ANT transport; a nonzero integer skips ANT and runs Gaussian-only SCF. Use --noant 1 to enable this mode.
-s, --nosymm N00 retains symmetry; a nonzero integer disables symmetry in the Gaussian job. Use --nosymm 1 to disable it.
-gp, --gau_nprocshared N1Number of shared-memory cores allocated to Gaussian (integer).
-gm, --gau_mem SIZE800MBGaussian memory allocation limit, expressed as a string such as 800MB or 4GB.
-scf, --scf_type N0Gaussian pre-convergence SCF method: 0 uses the default method (labelled DISS in the code); 1 requests quadratic convergence, SCF=(QC). Other values are rejected.

Options with values require an argument. In particular, --noant and --nosymm take integers; they are not bare switches. Preserve the underscores in --gau_nprocshared, --gau_mem and --scf_type.

Examples

# LSDA calculation with Pulay mixing, 8 Gaussian cores and 4 GB memory
poetry run ant-gau-open contact.com --model-xc lsda --mixing-type pulay --gau_nprocshared 8 --gau_mem 4GB

# Linear mixing, tighter density convergence and a 500-cycle limit
poetry run ant-gau-open contact.com --mixing-type linear --convergence-tolerance 1e-7 --num-scf-max 500

# Gaussian-only calculation with symmetry disabled and QC pre-convergence
poetry run ant-gau-open contact.com --noant 1 --nosymm 1 --scf_type 1

ANT parameters read from the calculation’s input files are separate from these command-line controls. Reference: command-line parser (authorised users). Defaults were checked against the repository on 26 November 2026.
