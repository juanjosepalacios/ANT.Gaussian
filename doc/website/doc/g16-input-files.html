ANT.Gaussian16

Input files

ANT.Gaussian16 is run through ant-gau-open. The examples below are taken from its repository and show Gaussian geometry/basis input, ANT transport parameters and optional basis/ECP files.

Files for a calculation

  • job.com or job.gjf: Gaussian route, title, charge/multiplicity and coordinates.
  • job.ant: ANT transport parameters, kept alongside the Gaussian input with the same job-name stem.
  • job.gbs, when supplied: the basis and effective core potential data required by that example.
  • job.baf: Gaussian binary archive used for supported restart workflows; it is generated by a calculation rather than written by hand.

Use the shared keyword reference for ANT parameters and the Gaussian16 command-line reference for driver settings. These inputs use the Python/GauOpen workflow; they do not need Gaussian09’s ANT %Subst directives.

Au4-Au-Au-Au4.gbs

Download Au4-Au-Au-Au4.gbs

Keep this file beside the Gaussian input; the input references it with an @ include.

First run the equilibrium example in examples/Au-nanocontact/ with --model-xc lsda. Copy its converged archive into the finite-bias working directory:

cp ../Au4-Au-Au-Au4.baf Au4-Au-Au-Au4.baf

Keep the finite-bias .ant and .gbs files in that directory, then run:

poetry run ant-gau-open Au4-Au-Au-Au4.baf --num-scf-max 500 --convergence-tolerance 1e-6 --model-xc lsda

Source: repository example (authorised users).

Further examples in the repository

The repository also includes spin-polarised nickel contacts, aluminium–benzene–aluminium junctions, platinum contacts and saved-archive restarts. Start with the README in each example directory; keep all accompanying input files together.
